# Сводный отчёт по услугам (VBA-макрос)

Макрос `modSummary1` для Excel собирает из папки с отчётами («Принимаем Отчет№*_...*.xlsx»)
сводный отчёт по услугам: динамика по периодам, расхождения по тарифам, детализация, графики.

## Состав

| Файл | Что это |
|---|---|
| `modSummary1.bas` | сам модуль (импортируется в VBA; файл в кодировке CP1251) |
| `Макрос отчета.xlsm` | рабочая книга, модуль уже внутрь встроен |
| `README.md` | эта инструкция |

## Как пользоваться

1. Откройте книгу `Макрос отчета.xlsm` (разрешите макросы).
2. Alt+F8 → выберите макрос → «Выполнить»:

| Макрос | Назначение |
|---|---|
| **Главная** | пересобрать отчёт и показать итог |
| **ВыбратьПапку** | указать свою папку с отчётами (запоминается в книге) |
| **ДобавитьФайлы** | добавить отдельные файлы из любого места (Ctrl — несколько) |
| **ОчиститьДопФайлы** | забыть добавленные файлы |
| `BuildSummary` | то же, что «Главная» (удобно для кнопки на листе) |

По умолчанию макрос берёт файлы из подпапки `отчеты` рядом с книгой.
Настройки (папка и список дополнительных файлов) хранятся в свойствах документа книги,
так что книга переносится вместе с ними.

Результат — файл `Сводный отчет по услугам (макрос).xlsx` рядом с книгой, 6 листов:

- **Сводка** — матрица «услуга × месяц» с подсветкой роста/снижения (порог подсветки задаётся в ячейке B4);
- **% изменений** — процентовка к предыдущему периоду;
- **Расхождения** — все замеченные изменения тарифов с цветовой маркировкой;
- **Графики** — диаграммы с выпадающими списками услуг;
- **Детализация** — построчный разбор;
- **Исходные отчёты** — реестр обработанных файлов.

После сборки выводится итог: сколько файлов найдено / разобрано / не распознано, число услуг, периодов и расхождений.

## Важные детали

- Не удаляйте старые отчёты из папки: отчёт пересобирается по всему содержимому,
  старые периоды нужны как база для сравнения.
- Не кладите в папку `отчеты` посторонние .xlsx — они попадут в «не распознано».
- Дедупликация работает только для одного и того же пути;
  копия файла из той же папки, добавленная через «ДобавитьФайлы», посчитается дважды.
- Условное форматирование использует русские имена функций (`И`, `ЕЧИСЛО`) —
  на русском Excel английские имена в правилах УФ молча не работают.
- Модуль хранится в CP1251; спецсимволы (₽, Δ, →, №, «, ») вставляются через `ChrW`.

## Требования

- Excel для Windows (используются VBA, FileDialog и российская локаль для УФ).
